# 오픈스카이 도티 사이트 작업 인계

도티두잇 안내와 회사 AdMob 인증 파일을 별도 사이트 저장소에서 관리한다. 기존 앱과 법적 고지 사이트는 수정하지 않았다.

## 현재 상태

사이트와 인증 파일 구현, 로컬 검증, `main` 병합 및 원격 푸시를 마쳤다. 구현 커밋은 `4a142180c3d5206a8cefab41494942982cd3e8c2`다. 최초 Actions 실행은 성공했으나 기본 브랜치 배포가 함께 실행되어 공개 홈이 README로 바뀌고 인증 파일은 404였다. 사용자가 Pages Source를 GitHub Actions로 변경했다고 확인했으며, 설정 변경 후 재배포와 공개 응답을 확인하는 단계다.

- 저장소: `opensky-doti/opensky-doti.github.io`
- 앱 소개: `https://opensky-doti.github.io/dotidoit/`
- 인증 파일: `https://opensky-doti.github.io/app-ads.txt`
- 앱 설정에 사용할 실제 광고 ID·실광고 모드는 이번 작업 범위가 아니다.

## 검증 기록

- 인증 파일·HTML·배포 워크플로 계약 검사: 21개 테스트 통과.
- 로컬 브라우저: 세 페이지 × 320·390·1280px × 글자 100·200%의 18개 표시 검사 통과.
- 메뉴, 본문 바로가기, 오류 페이지 홈 복귀, 다운로드 링크 확인 통과. 페이지 JavaScript 오류 없음.
- 확정 아이콘 복사본 SHA-256이 원본과 동일함을 확인했다.
- QA 산출물은 작업 폴더의 git 제외 경로 `output/browser-qa/`에 있다.

## 운영상의 판단

브라우저 연동 도구에서 사용 가능한 브라우저가 없어, 새 프로필의 headless Chrome으로 로컬 사이트만 검사했다. 사용자 브라우저의 로그인 정보를 읽거나 사용하지 않았다. GitHub 웹 설정은 접근 가능한 별도 인증 수단이 없으면 사용자가 직접 진행해야 한다.

워크플로는 Python 표준 라이브러리로 읽을 수 있는 JSON 문법의 YAML을 사용한다. 소스 문자열 검사를 대신해 파싱된 배포 조건과 업로드 범위에 대한 검사를 제공하며, 실제 Actions 성공은 별도로 확인한다.

## 다음 단계
