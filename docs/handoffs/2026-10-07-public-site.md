# 오픈스카이 도티 사이트 작업 인계

도티두잇 안내와 회사 AdMob 인증 파일을 별도 사이트 저장소에서 관리한다. 기존 앱과 법적 고지 사이트는 수정하지 않았다.

## 현재 상태

2026-10-07 사이트와 인증 파일 구현, 검증, `main` 병합·푸시 및 GitHub Pages 공개를 완료했다. 구현 커밋은 `4a142180c3d5206a8cefab41494942982cd3e8c2`, 공개 검증 대상은 문서 보완 커밋 `c6492d170f860b7ad3c5aac1778fc745a1b58d43`다. [배포 실행 37636388616](https://github.com/opensky-doti/opensky-doti.github.io/actions/runs/37636388616)의 검증과 배포가 성공했다.

최초 Actions 실행은 성공했으나 기본 브랜치 배포가 함께 실행되어 공개 홈이 README로 바뀌고 인증 파일은 404였다. 사용자가 Pages Source를 **GitHub Actions**로 변경한 뒤 재배포해 해결했다. 기존 워크플로 코드는 바꾸지 않았다. 이후에도 이 소스 설정을 유지한다.

- 저장소: `opensky-doti/opensky-doti.github.io`
- 앱 소개: `https://opensky-doti.github.io/dotidoit/`
- 인증 파일: `https://opensky-doti.github.io/app-ads.txt`
- 앱 설정에 사용할 실제 광고 ID·실광고 모드는 이번 작업 범위가 아니다.

## 검증 기록

- 인증 파일·HTML·배포 워크플로 계약 검사: 21개 테스트 통과.
- 로컬 브라우저: 세 페이지 × 320·390·1280px × 글자 100·200%의 18개 표시 검사 통과.
- 메뉴, 본문 바로가기, 오류 페이지 홈 복귀, 다운로드 링크 확인 통과. 페이지 JavaScript 오류 없음.
- 공개 사이트에서도 동일한 18개 표시 검사와 링크·키보드 이동 검사를 통과했다. 공개 모바일 화면도 이미지로 확인했다. 실물 휴대폰 테스트나 브라우저 자체 확대가 아니라 Chrome의 화면 너비·루트 글자 크기 변경 검사다.
- 공개 `/`, `/dotidoit/`는 HTTP 200이며 소스 HTML과 바이트 단위로 일치한다.
- 공개 `/app-ads.txt`는 HTTP 200, `text/plain; charset=utf-8`, 59바이트이며 게시자 `pub-3081928577042149`를 포함한 소스 파일과 정확히 일치한다.
- 존재하지 않는 `/missing-page-20261007`는 HTTP 404이며 사용자 정의 `site/404.html`과 일치한다.
- 확정 아이콘 복사본 SHA-256이 원본과 동일함을 확인했다.
- QA 산출물은 작업 폴더의 git 제외 경로 `output/browser-qa/`에 있다.

## 운영상의 판단

브라우저 연동 도구에서 사용 가능한 브라우저가 없어 새 프로필의 headless Chrome으로 로컬·공개 사이트를 검사했다. 사용자 브라우저의 로그인 정보를 읽거나 사용하지 않았다. GitHub 웹 설정은 사용자가 직접 변경했고 결과는 재배포와 공개 응답으로 확인했다. Safari·Firefox는 별도 검증하지 않았다.

워크플로는 Python 표준 라이브러리로 읽을 수 있는 JSON 문법의 YAML을 사용한다. 소스 문자열 검사를 대신해 파싱된 배포 조건과 업로드 범위에 대한 검사를 제공하며, 실제 Actions 성공은 별도로 확인한다.

최종 검토는 신규 검토 에이전트 생성 한도로 인해 기존 완료된 검토 에이전트에 독립적인 읽기 전용 사이트 검토를 맡겼다. 사이트 구현에 참여하지 않은 검토였지만 완전히 새로운 에이전트 문맥은 아니었다. 중요도별 지적 사항은 없었고, 검토 범위 밖이었던 실제 Actions·공개 HTTP 검증은 배포 후 별도로 통과했다.

콘솔 인증과 실광고 전환은 사이트 공개와 분리한다. 이번 작업으로 AdMob 인증 완료나 광고 수익 발생까지 확인한 것은 아니다. 기존 앱·APK·AAB·법적 고지와 테스트 광고 설정은 변경하지 않았다.

## 다음 단계

1. Play Console 도티두잇의 스토어 등록정보 연락처 웹사이트에 `https://opensky-doti.github.io/dotidoit/`를 입력하고 저장·공개 반영한다. `/app-ads.txt` 주소를 웹사이트 칸에 입력하지 않는다.
2. 실제 Play 스토어 앱 지원 영역에서 웹사이트가 반영됐는지 확인한다.
3. AdMob 앱 인증 화면에서 **업데이트 확인**을 누른다. Google 탐색·반영 지연 또는 추가 안내가 있으면 그 결과를 확인한다.
4. 인증 이후 앱 ID·광고 단위 ID, 개인정보·광고 선언 등을 별도 점검한 뒤 앱의 실광고 전환을 진행한다. 현재 테스트 광고를 임의로 전환하지 않는다.

회사 컴퓨터에서는 이 저장소를 clone/pull하여 이어간다. 세부 검사·배포·복구 절차는 [README](../../README.md)를 따른다. 문서 보완 커밋은 사이트 파일을 변경하지 않는다.
